##  Proyectos

###  Homelab — Infraestructura con Docker y VPN
Entorno local desplegado sobre Ubuntu Server con acceso remoto seguro.
- 4–6 servicios corriendo en contenedores Docker simultáneamente
- Acceso remoto configurado con **Tailscale (VPN mesh)** y **SSH con llaves públicas**
- Red interna con DHCP, DNS local y monitoreo de tráfico

###  Red LAN — Cisco Packet Tracer
Diseño y configuración de red empresarial simulada.
- Topología con 3+ switches, 2 routers y 4 segmentos de red
- **4 VLANs** con Inter-VLAN routing, DHCP centralizado y ACLs de seguridad
- Documentación completa: diagramas, tabla de direccionamiento IP y comandos de verificación

###  Laboratorio de Active Directory — Windows Server
Implementación de directorio de identidades en entorno virtualizado.
- Dominio local configurado con **Active Directory Domain Services (AD DS)** en VirtualBox
- Usuarios, grupos y unidades organizativas (OUs) creados y administrados
- Políticas de grupo (**GPOs**) básicas aplicadas para seguridad y gestión de escritorio

###  Análisis Exploratorio de Datos — Python
Pipeline básico de análisis de datos con Python.
- Limpieza y transformación de datasets de 1,000+ registros con **pandas**
- 5+ visualizaciones descriptivas con **matplotlib** y **seaborn**
